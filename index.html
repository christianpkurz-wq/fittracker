Share with Coach
Set up once — your coach sees everything live.
Step 1 — Host this app
GitHub Pages (free, permanent)
1. Go to github.com → sign up free
2. New repo → name fittracker → Public → Create
3. Upload index.html → Commit
4. Settings → Pages → Branch: main → Save
5. URL: yourusername.github.io/fittracker
Step 2 — Share Google Sheet
Coach sees live data after every export
1. Open Data Tracking Google Sheet
2. Share → Anyone with the link → Viewer
3. Copy link → send to coach
4. Tap Export CSV in the app → import into Sheets → coach refreshes
Step 3 — Phone home screen
iPhone: Open URL in Safari → Share → Add to Home Screen
Android: Open in Chrome → ⋮ → Add to Home Screen
