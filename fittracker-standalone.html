Share with Coach
Two things to set up once — then your coach sees everything live.
Step 1 — Host this app (one time)
Get a permanent link via GitHub Pages
1. Go to github.com → sign up free if needed
2. Click New repository → name it fittracker → Public → Create
3. Click Add file → Create new file → name it index.html
4. Paste the full HTML from this app → click Commit changes
5. Go to Settings → Pages → Source: main branch → Save
6. Your URL: yourusername.github.io/fittracker — permanent, free forever
Step 2 — Share Google Sheets with coach (one time)
Coach sees your data live after every sync
1. Open your Data Tracking Google Sheet
2. Click Share (top right) → Change to Anyone with the link
3. Set permission to Viewer → Copy link
4. Send that link to your coach — he can bookmark it and check anytime
5. You hit Sync in the app → sheet updates → coach refreshes to see it
Step 3 — Add to home screen (phone)
Install as app icon on your phone
iPhone: Open your GitHub Pages URL in Safari → tap Share → Add to Home Screen → Add

Android: Open in Chrome → tap ⋮ menu → Add to Home Screen or Install app
Step 4 — Add to computer
Install as desktop app (Chrome)
Open your GitHub Pages URL in Chrome → click the install icon in the address bar → Install
Or: 3-dot menu → Save and share → Install page as app
What your coach sees
Your Google Sheet has all your data: weight, calories, steps, blood pressure, blood glucose, training volume — organized by week and day. Every time you tap Sync in the app, it updates. Coach just refreshes the sheet.
